# LZT Terminal Trader 🚀
### Мультиагентная консольная система анализа рынка и автоматизации арбитража Telegram-аккаунтов на LZT Market

**LZT Terminal Trader** — это готовый к ежедневному практическому использованию консольный терминал на Python для поиска выгодных предложений, многоуровневой проверки рисков, расчёта чистой доходности с точностью до копейки (`Decimal`), безопасного проведения разрешённых закупок и автоматизированной подготовки перепродажи.

Интерфейс построен на библиотеке **Rich** с интуитивной цифровой навигацией, встроенным мастером первоначальной настройки и надёжной защитой от финансовых потерь и Prompt Injection.

---

## ⚡ Быстрый старт

### 1. Системные требования
* **Python**: 3.11 или новее
* **ОС**: Linux, macOS или Windows (с поддержкой терминала UTF-8)
* **Сеть**: Доступ к `api.lzt.market`

### 2. Клонирование и установка

```bash
# Клонирование репозитория
git clone https://github.com/<owner>/lzt-terminal-trader.git
cd lzt-terminal-trader

# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### 3. Запуск программы

```bash
python main.py
```

> **Совет:** При первом запуске программа автоматически определит отсутствие конфигурационного файла `.env` и запустит интерактивный 5-шаговый мастер первоначальной настройки (**Setup Wizard**) прямо в терминале.

## 🧭 Навигация и разделы меню терминала

Консольный интерфейс разделён на 12 функциональных модулей с удобной цифровой навигацией:

```text
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃                     LZT TERMINAL TRADER v2.0                                ┃
┃            SIMULATION MODE — REAL TRANSACTIONS DISABLED                     ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
[ 1] Главная панель (Dashboard)      [ 7] Перепродажа (Resale Listings)
[ 2] Сканер рынка (Market Scanner)   [ 8] Финансы и ведомость (Finance)
[ 3] Анализ лота (Listing Analysis)  [ 9] Настройки (Settings)
[ 4] Калькулятор прибыли (Calc)      [10] API Соединение (API Connection)
[ 5] Агенты и Оркестратор (Agents)   [11] Журнал логов (Logs)
[ 6] Управление закупками (Purchases)[12] Диагностика (Diagnostics)
                                     [ 0] Выход из программы (Exit)
```

### Описание разделов:
1. **Главная панель (Dashboard)**: Сводка финансового состояния в реальном времени: баланс, расходы за сутки, остаток суточного бюджета, количество черновиков перепродажи, реализованная прибыль и текущие статусы всех автономных агентов.
2. **Сканер рынка (Market Scanner)**: Поиск Telegram-аккаунтов по ключевым словам, стране, диапазону цен. Проводит автоматический скоринг риска, расчёт справедливой цены перепродажи и прогнозируемого ROI.
3. **Анализ лота (Listing Analysis)**: Глубокая инспекция конкретного объявления по его ID. Выявляет противоречия между текстом продавца и техническими параметрами лота (спамблок, 2FA, возраст, гео), сканирует на Prompt Injection.
4. **Калькулятор прибыли (Profit Calculator)**: Финансовый движок на `Decimal`. Мгновенно рассчитывает комиссии покупателя и продавца, чистую прибыль, процент ROI и точную точку безубыточности (`ROUND_CEILING`).
5. **Агенты и Оркестратор (Agents)**: Мониторинг специализированных агентов и запуск сквозного координированного цикла арбитража (`Orchestrator Cycle`).
6. **Управление закупками (Purchases)**: История операций, статус исполнения, сохранённые сессионные данные и возможность прямой покупки по ID лота со строгим контролем лимитов.
7. **Подготовка и перепродажа (Resale Listings)**: Инвентарь купленных аккаунтов, автоматическая генерация прозрачных описаний (без скрытия дефектов) и публикация на LZT Market.
8. **Финансы и ведомость (Finance)**: Главная бухгалтерская книга (Ledger). Хранит историю каждого списания и начисления, позволяет пополнять баланс песочницы.
9. **Настройки (Settings)**: Управление параметрами `.env`, переключение между режимами симуляции и реальной торговли, изменение лимитов бюджета.
10. **API Соединение (API Connection)**: Проверка доступности серверов LZT Market, измерение задержки сети (ping) и верификация Bearer API токена.
11. **Журнал логов (Logs)**: Системный журнал событий с фильтрацией по уровням (INFO, WARNING, ERROR).
12. **Диагностика (Diagnostics)**: Автоматическая проверка целостности окружения (версия Python, библиотеки, файл `.env`, база данных SQLite, валидность токена).
0. **Выход (Exit)**: Безопасное завершение работы с сохранением данных.

## 🛡️ Безопасность и режимы работы

### 1. Режим симуляции (Simulation Mode — включён по умолчанию)
В верхней части экрана отображается предупреждающий баннер:
`SIMULATION MODE — REAL TRANSACTIONS DISABLED`

* Реальные финансовые транзакции и списания средств с аккаунта **полностью заблокированы**.
* Для тестирования предоставляется реалистичный встроенный каталог предложений.
* Стартовый виртуальный баланс песочницы: **10,000.00 RUB**.
* Позволяет протестировать весь пайплайн (поиск, анализ, покупка, выставление на перепродажу) без риска.

### 2. Реальный режим (Live Mode)
Для активации реальных покупок требуется соблюдение **всех 4 условий одновременно**:
1. `APP_MODE=live` в `.env`.
2. `SIMULATION_MODE=false`.
3. `LIVE_PURCHASE_ENABLED=true` (глобальный kill-switch).
4. Указан действующий токен `LZT_API_TOKEN`.

### 3. Механизмы защиты:
* **Защита от состояния гонки (TOCTOU):** Синхронная блокировка `_in_flight_locks` предотвращает случайную параллельную покупку одного и того же аккаунта.
* **Бюджетные предохранители:** Жесткий суточный лимит (`MAX_DAILY_BUDGET`), максимальная цена единичного лота (`MAX_PURCHASE_PRICE`), блокировка нулевых и отрицательных цен.
* **Ручное подтверждение:** По умолчанию покупка каждого лота требует подтверждения оператора (`MANUAL_PURCHASE_CONFIRMATION=true`).
* **Точка безубыточности с округлением вверх (`ROUND_CEILING`):** Гарантирует покрытие всех комиссий маркета даже при копеечных округлениях.
* **Защита от Prompt Injection:** Очистка текста от zero-width символов (`\u200b`), NFKD-нормализация против омоглифов и строгие регулярные выражения для блокировки попыток манипуляции решением агента.
* **Контроль противоречий:** Сверка геотега `[XX]` в заголовке с реальной страной `country`, сверка заявляемого года (2019-2023) с фактическим возрастом аккаунта, устойчивость к фразам `"not clean"` / `"без спамблока"`.

## 🔑 Настройка LZT Market API

1. Авторизуйтесь на [lzt.market](https://lzt.market).
2. Перейдите в профиль: **Настройки** → **Доступ к API**.
3. Сгенерируйте API Token с необходимыми правами доступа к рынку.
4. Введите токен при первом запуске через мастера настройки или укажите в `.env`:
   ```env
   LZT_API_TOKEN=ваш_токен_здесь
   ```
   > **Важно:** Никогда не передавайте ваш токен третьим лицам и не коммитьте файл `.env` в публичные репозитории. Файл `.env` внесён в `.gitignore`.

## ❓ Устранение неполадок (Troubleshooting)

* **Ошибка 401 / 403 при вызове API:** Проверьте правильность токена через пункт меню `[10] API Соединение` или запустите диагностику `python main.py --diag`.
* **Ошибка 429 (Rate Limit):** Встроенный клиент автоматически регулирует частоту запросов в соответствии с параметром `LZT_RATE_LIMIT_RPS` (по умолчанию 3.0 RPS). При возникновении снизьте параметр в настройках.
* **Падение при нестандартных символах в терминале:** Убедитесь, что кодировка терминала установлена в UTF-8 (`export LANG=en_US.UTF-8`).
