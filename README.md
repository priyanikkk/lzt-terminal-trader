# LZT Terminal Trader 🚀
### Мультиагентная консольная система арбитража аккаунтов Telegram на LZT Market

**LZT Terminal Trader** — это готовая к ежедневному использованию терминальная программа на Python с красивым интерфейсом на **Rich**, строгой системой безопасности, детерминированным финансовым движком (на базе `Decimal`), встроенным интерактивным мастером настройки и защитой от инъекций в описаниях объявлений.

---

## ⚡ Быстрый старт (Запуск в 1 команду)

1. Откройте терминал и перейдите в папку с проектом:
   ```bash
   cd /home/prun/Descargas/lztmarket
   ```

2. Активируйте виртуальное окружение:
   ```bash
   source .venv/bin/activate
   ```

3. Запустите программу:
   ```bash
   python main.py
   ```

При первом запуске программа автоматически обнаружит отсутствие настроек и запустит **интерактивный мастер первоначальной настройки (Setup Wizard)** из 5 простых шагов прямо в терминале!

## 🧭 Интерактивное меню терминала

Интерфейс спроектирован по принципу максимальной наглядности с цифровой навигацией:

```text
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃                     LZT TERMINAL TRADER v2.0                                ┃
┃            SIMULATION MODE — REAL TRANSACTIONS DISABLED                     ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
[ 1] Главная панель (Dashboard)      [ 7] Перепродажа (Resale Listings)
[ 2] Сканер рынка (Market Scanner)   [ 8] Финансы и ведомость (Finance)
[ 3] Анализ лота (Listing Analysis)  [ 9] Настройки (Settings)
[ 4] Калькулятор прибыли (Calc)      [10] API Соединение (API Connection)
[ 5] Агенты и Оркестратор (Agents)   [11] Журнал логов (Logs)
[ 6] Управление закупками (Purchases)[12] Диагностика (Diagnostics)
                                     [ 0] Выход из программы (Exit)
```

Каждый пункт меню полностью реализован, интерактивен и выполняет реальные операции:

1. **Главная панель (Dashboard)**: Отображает текущий баланс, сумму покупок за сегодня, остаток дневного лимита, количество черновиков перепродажи, реализованную чистую прибыль и статус всех агентов.
2. **Сканер рынка (Market Scanner)**: Поиск объявлений Telegram с настраиваемыми фильтрами (цена, страна, поисковый запрос). Показывает оценку рисков, расчётную перепродажу и ROI. Позволяет выбрать любой лот для покупки.
3. **Анализ лота (Listing Analysis)**: Детальная проверка объявления по ID. Проверяет наличие скрытых паролей 2FA, спамблока, противоречий между текстом продавца и реальными параметрами, а также сканирует на попытки Prompt Injection.
4. **Калькулятор прибыли (Profit Calculator)**: Интерактивный калькулятор на `Decimal`. Задайте цену закупки и желаемую цену продажи — программа мгновенно рассчитает комиссии покупателя/продавца, чистую прибыль, ROI и точку безубыточности.
5. **Агенты и Оркестратор (Agents)**: Статус и статистика 6 специализированных агентов. Позволяет запустить единый сквозной цикл арбитража (`Orchestrator Cycle`).
6. **Управление закупками (Purchases)**: История всех покупок, статусы, цены и инструмент прямой покупки по ID лота со строгой проверкой лимитов.
7. **Подготовка и перепродажа (Resale Listings)**: Управление купленным инвентарём, автоматическая генерация честных описаний (без обмана и ложных обещаний) и публикация лотов на маркет.
8. **Финансы и ведомость (Finance)**: Прозрачная книга учёта транзакций (Ledger). Показывает баланс, остаток суточного бюджета и позволяет пополнять виртуальный баланс в режиме песочницы.
9. **Настройки (Settings)**: Просмотр текущей конфигурации, переключение режимов `Simulation <-> Live`, изменение финансовых лимитов или повторный запуск мастера настройки.
10. **API Соединение (API Connection)**: Проверка связи с `https://api.lzt.market`, пинг в миллисекундах, статус авторизации и баланс аккаунта.
11. **Журнал логов (Logs)**: Просмотр системных событий с фильтрацией по уровням (INFO, WARNING, ERROR).
12. **Диагностика (Diagnostics)**: Комплексная проверка готовности системы (версия Python, библиотеки, файл `.env`, база данных SQLite, доступность серверов LZT Market).
0. **Выход (Exit)**: Корректное завершение работы программы.

## 🛡️ Безопасность и Режимы работы

### 1. Режим симуляции (Simulation Mode — включён по умолчанию)
В верхней части терминала всегда отображается баннер:
`SIMULATION MODE — REAL TRANSACTIONS DISABLED`

В этом режиме:
- Программа **НЕ тратит реальные деньги** и не отправляет запросы на списание средств.
- Используется реалистичный каталог Telegram-аккаунтов для безопасного тестирования всех функций.
- Виртуальный баланс по умолчанию составляет **10,000.00 RUB**.
- Можно безопасно обучиться работе с терминалом и отладить стратегию.

### 2. Реальный режим (Live Mode)
Для включения реальной торговли требуются три явных условия:
1. `APP_MODE=live` в `.env`.
2. `LIVE_PURCHASE_ENABLED=true`.
3. Указан действительный Bearer API Token от LZT Market.

В реальном режиме действует **многоуровневая система защиты**:
- **MAX_DAILY_BUDGET**: Защита от перерасхода (по умолчанию 3000.0 RUB в сутки).
- **MAX_PURCHASE_PRICE**: Максимальная цена покупки одного лота (по умолчанию 350.0 RUB).
- **MIN_ROI_PERCENT**: Минимальный порог рентабельности сделки (по умолчанию 25%).
- **Ручное подтверждение**: По умолчанию программа всегда запрашивает подтверждение оператора перед покупкой.
- **Idempotency Lock**: Защита от случайной двойной покупки одного и того же аккаунта.

## 🔑 Как получить токен LZT Market API

1. Зайдите на сайт [lzt.market](https://lzt.market).
2. Перейдите в свой профиль: **Настройки** -> **Доступ к API**.
3. Создайте токен с разрешениями на чтение объявлений и покупку.
4. Скопируйте полученный ключ.
5. Введите его в мастере настройки программы (`python main.py --wizard`) или пропишите в `.env`:
   ```env
   LZT_API_TOKEN=ваш_токен_здесь
   ```

## 🤖 Мультиагентная архитектура

Система построена на принципах модульности внутри единого стабильного Python-процесса (без лишних серверов и накладных расходов):

- `OrchestratorAgent`: Диспетчер процессов, координирует цепочку и следит за ошибками.
- `MarketScannerAgent`: Сканирует рынок, применяет фильтры гео и цен.
- `ListingInspectorAgent`: Анализирует описания, находит противоречия и блокирует Prompt Injection.
- `PricingAgent`: Вычисляет справедливую цену, комиссии маркета и чистый ROI.
- `PurchaseAgent`: Контролирует лимиты, проверяет валидность лота и совершает покупку.
- `ResaleAgent`: Генерирует честный текст описания и публикует на продажу.
- `FinanceAgent`: Ведёт книгу учёта (Ledger) и аудит суточного бюджета.
