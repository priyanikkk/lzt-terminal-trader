# Руководство по API-интеграции LZT Market и Telegram

## 1. Взаимодействие с LZT Market API

Клиент `api/lzt_client.py` реализует работу с официальным REST API LZT Market (`https://api.lzt.market`).

### 1.1 Авторизация
Запросы передаются с заголовком:
```http
Authorization: Bearer <LZT_API_KEY>
```
Если ключ не указан в `.env`, клиент автоматически переходит в режим автономного высокоточного симулятора со сгенерированным набором типовых лотов (чистые аккаунты, спамблоки, 2FA, завышенные цены, промпт-инъекции).

### 1.2 Используемые эндпоинты

| Метод | Эндпоинт | Назначение |
|---|---|---|
| `GET` | `/telegram` | Поиск объявлений по фильтрам (`pmin`, `pmax`, `origin`, `order_by`) |
| `GET` | `/{item_id}` | Получение полной спецификации конкретного лота |
| `GET` | `/{item_id}/check` | Быстрая проверка актуальности лота на маркете |
| `POST` | `/{item_id}/fast-buy` | Покупка аккаунта по указанной цене |
| `POST` | `/item/add` | Публикация лота на перепродажу |
| `GET` | `/me` | Проверка баланса и профиля пользователя |

### 1.3 Ограничение частоты запросов (Rate Limiting)
- Клиент реализует встроенный троттлинг на основе параметра `LZT_RATE_LIMIT_RPS` (по умолчанию 3 запроса/сек).
- При получении HTTP `429 Too Many Requests` клиент считывает заголовок `Retry-After` и выполняет экспоненциальную паузу перед повторной попыткой.

## 2. Управляющий Telegram Бот

Клиент `api/telegram_client.py` взаимодействует с официальным Telegram Bot API:

### Формат отправляемых уведомлений:
1. **Находка связки:** Название лота, цена покупки, предполагаемая цена перепродажи, ожидаемая чистая прибыль, ROI.
2. **Исполнение покупки:** Номер заказа, потраченная сумма, режим (`[SIMULATION]` или `[LIVE]`).
3. **Блокировка риском:** Уровень риска, список флагов, причины вето.
4. **Аварийный выключатель:** Срабатывание circuit breaker и остановка процесса.

> **Важно:** Бот отправляет исключительно управленческие и статистические уведомления. Сбор SMS, пересылка кодов авторизации и попытки обхода двухфакторной аутентификации строго запрещены на уровне архитектуры.
